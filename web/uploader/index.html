openFrameworks → the web

Put your sketch online in one click.

Drop in your openFrameworks source files. This sets up a GitHub repository on your account that builds your sketch to WebAssembly and publishes it at a public link — no compilers, no command line.

1 Connect GitHub

Create a quick access token so the app can make one repository for you. It's kept only in this browser tab, and you can delete it on GitHub anytime.

  1. Open the pre-filled token page↗ — the needed permissions (public_repo, workflow) are already ticked.
  2. Pick an expiration, scroll down, and click Generate token.
  3. Copy it and paste it here:

Signed in as
2 Name your project

This becomes your repository name and part of your live URL.

Live at https://you.github.io/my-of-sketch/

3 Add your files

Drag in your whole openFrameworks project folder, a .zip of it, or individual files. Code goes to src/ and assets to bin/data/, automatically.
