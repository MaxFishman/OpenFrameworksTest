# 01 — connect github

Create an access token

The app makes one repository for you using a token that stays only in this browser tab. You can delete it on GitHub anytime.

  1. Open the pre-filled token page↗ — the scopes public_repo, workflow are already ticked.
  2. Pick an expiration, scroll down, and click Generate token.
  3. Copy it and paste it below.
